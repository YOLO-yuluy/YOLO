========================================
  YOLO 实时人脸检测程序 —— 使用说明
========================================


【一、软件简介】
---------------
这是一个基于 YOLOv8n-face 轻量化模型的实时人脸检测程序。
打开摄像头后，程序会自动识别画面中的人脸，并用彩色矩形框标出。

主要特点：
  ✅ 已打包成 exe，双击即可运行，无需安装 Python
  ✅ 轻量化模型，CPU 即可流畅运行（20fps 以上）
  ✅ 仅检测人脸，不包含人脸识别、年龄、性别等功能
  ✅ 支持多语言界面（中文 / English / 日本語 / 한국어）
  ✅ 检测框颜色可自定义（8 种预设 + 自定义调色板）
  ✅ 置信度 0.5 过滤低质量人脸，NMS 去重
  ✅ 容忍偶发摄像头丢帧，不会轻易自动停止
  ✅ 模型已内置在 exe 中，无需联网下载


【二、exe 文件在哪里下载？】
---------------------------

  ⚠️ 重要：exe 文件不在仓库代码里！
  因为 exe 文件较大（约 326MB），超过了 GitHub 单文件 25MB 的限制，
  所以 exe 文件放在【Releases 发布页面】中。

  ▎下载步骤：
    1. 打开本项目的 GitHub 页面
    2. 在仓库页面右侧，找到「Releases」字样，点击进入
       （或者直接访问 Releases 页面链接）
    3. 找到最新版本（例如 v1.0）
    4. 在版本说明下方的「Assets」区域，会看到附件列表
    5. 点击「人脸检测.exe」开始下载
    6. 等待下载完成（文件约 326MB，请耐心等待）

  ▎如果找不到 Releases：
    - 方法 1：在仓库页面点击右侧「Releases」标签
    - 方法 2：在仓库网址末尾加上 /releases
              例如：https://github.com/用户名/仓库名/releases
    - 方法 3：如果仓库主页看不到 Releases，
              可能是还没有发布版本，请联系作者

  ▎下载后：
    - 下载到的文件名是「人脸检测.exe」
    - 把它放在任意文件夹都可以运行
    - 不需要其他任何文件，单独一个 exe 就够了


【三、运行环境要求】
-------------------

  操作系统：Windows 10 / 11（64 位）

  硬件要求：
  - 必须有可用的摄像头（USB 摄像头或笔记本内置摄像头）
  - CPU：双核以上即可，推荐 i5 及以上
  - 内存：至少 2GB 可用内存
  - 硬盘：至少 500MB 可用空间（exe 文件约 326MB）

  网络：无需联网，模型已内置在 exe 中


【四、启动程序】
---------------

▎方法一：双击 exe 启动（推荐）
  1. 从 Releases 页面下载「人脸检测.exe」
  2. 双击该文件即可启动

  首次启动说明：
  - 首次启动会稍慢（约 10~30 秒），因为需要解压依赖到临时目录
  - 之后启动速度会正常
  - 启动过程中会显示「正在加载模型，请稍候...」
  - 如果杀毒软件拦截，请添加信任后重试

▎方法二：用 Python 运行源代码（备用方案）
  如果 exe 无法运行，可以用 Python 运行源代码：
  1. 安装 Python 3.10 或 3.11（勾选 Add Python to PATH）
     下载地址：https://www.python.org/downloads/
  2. 从 GitHub 仓库下载源代码（main.py、requirements.txt 等）
  3. 安装依赖：
     打开命令提示符（Win+R，输入 cmd，回车）
     进入程序目录：
       cd /d 程序所在目录
     执行：
       pip install -r requirements.txt
  4. 运行程序：
       python main.py


【五、界面说明】
---------------

程序主界面从上到下分为三个区域：

┌─────────────────────────────────────────┐
│                                         │
│         【视频画面显示区】                │
│         640 × 480 像素                    │
│         显示摄像头实时画面 + 人脸框        │
│                                         │
├─────────────────────────────────────────┤
│  [开始检测]  [停止检测]        [⚙ 设置]  │   ← 底部控制区
├─────────────────────────────────────────┤
│  状态栏：显示当前状态 / 人脸数 / FPS     │   ← 最下方
└─────────────────────────────────────────┘


▎1. 视频画面显示区
  - 未启动时：显示黑色背景 + 提示文字
  - 检测中：实时显示摄像头画面，人脸被彩色矩形框标出
  - 画面尺寸：640 × 480 像素

▎2. 开始检测按钮
  - 点击后打开摄像头，开始实时人脸检测
  - 模型加载完成前此按钮为灰色不可用

▎3. 停止检测按钮
  - 点击后关闭摄像头，停止检测
  - 检测未开始时此按钮为灰色不可用

▎4. 设置按钮（⚙ 设置）
  - 位于右下角
  - 点击打开设置面板，可调整检测框颜色和界面语言
  - 详细说明见【六、设置功能】

▎5. 状态栏（最底部）
  显示当前程序状态，可能的内容包括：
  · 正在加载模型，请稍候 ...
  · 模型加载完成，点击「开始检测」启动摄像头。
  · 检测中  |  人脸数量：N  |  帧率：XX.X FPS
  · 已停止检测。点击「开始检测」重新启动。
  · 无法打开摄像头，请检查设备或权限。
  · 读取摄像头画面失败，已停止。


【六、设置功能详解】
-------------------

点击右下角「⚙ 设置」按钮打开设置面板。

设置面板包含两个区块：

▎区块一：检测框颜色
  可以调整人脸检测框的颜色。

  8 种预设颜色（点击即选）：
    绿色 / 红色 / 蓝色 / 黄色 / 青色 / 紫色 / 白色 / 橙色

  自定义颜色：
    点击「自定义颜色...」按钮，打开系统调色板：
    - 可以用鼠标点击选择任意颜色
    - 也可以手动输入 RGB 值（红/绿/蓝，0~255）
    - 点击「确定」应用，点击「取消」放弃

  当前颜色预览：
    「当前：」右侧的小方块显示当前选中的颜色

  注意：选择颜色后需要点击设置面板右下角的「确定」
        按钮才会真正生效。

▎区块二：界面语言
  可以切换整个软件界面的显示语言。

  支持 4 种语言：
    中文（简体）
    English（英语）
    日本語（日语）
    한국어（韩语）

  操作方法：
    1. 点击下拉菜单
    2. 选择你想要的语言
    3. 点击「确定」按钮
    4. 界面所有文字会立刻切换为对应语言

  切换语言影响范围包括：
    - 窗口标题
    - 按钮文字
    - 状态栏提示
    - 错误提示
    - 设置面板全部文字
    - 画面占位符文字

▎确定 / 取消按钮
  - 确定：保存所有设置并关闭面板
  - 取消：放弃修改，直接关闭面板


【七、使用技巧与注意事项】
-------------------------

▎检测效果最佳的条件
  ✔ 光线充足，面部清晰可见
  ✔ 人脸正对摄像头
  ✔ 面部无大面积遮挡（口罩、帽子等可能降低检测率）
  ✔ 摄像头距离面部 0.5 ~ 3 米效果最好

▎为什么侧脸/快速移动时检测框会消失？
  这是正常现象，不是程序出问题了。
  - 侧脸时人脸特征不明显，模型可能识别不到
  - 快速移动时画面模糊，也会影响检测
  - 程序不会因此自动停止，会继续检测下一帧

▎程序会不会自动停止？
  一般不会。只有以下情况会停止：
  1. 用户手动点击「停止检测」
  2. 用户关闭窗口
  3. 摄像头连续 30 帧读取失败（约 0.3 秒），
     判定为摄像头断开或被占用

  偶发的一帧两帧失败（比如人快速移动时），
  程序会自动跳过，继续检测下一帧。

▎可以同时检测多个人脸吗？
  可以。画面中有几张脸就会框出几张，没有数量限制。
  状态栏会显示当前检测到的人脸总数。


【八、常见问题 FAQ】
--------------------

Q1：exe 文件在哪里下载？
A ：exe 文件在 GitHub 仓库的 Releases 页面。
    步骤：
    1. 打开项目 GitHub 页面
    2. 点击右侧「Releases」
    3. 找到最新版本
    4. 在 Assets 区域点击「人脸检测.exe」下载
    仓库代码里不包含 exe（因为文件太大）。

Q2：双击「人脸检测.exe」没反应怎么办？
A ：可能是以下原因：
    ① 杀毒软件拦截了 exe 文件
       → 在杀毒软件中添加信任，或暂时关闭杀毒软件
    ② Windows SmartScreen 拦截
       → 点击「更多信息」→「仍要运行」
    ③ 首次启动较慢，请耐心等待 30 秒
    ④ 文件下载不完整，重新下载

Q3：exe 启动后弹出错误窗口怎么办？
A ：请记下错误信息。常见错误：
    · 「无法打开摄像头」→ 见 Q5
    · 「模型加载失败」→ exe 文件可能损坏，重新下载
    · 其他错误 → 尝试用 Python 运行 main.py 源代码

Q4：如何用 Python 运行源代码？
A ：步骤如下：
    1. 安装 Python 3.10 或 3.11（勾选 Add Python to PATH）
    2. 从 GitHub 下载源代码（main.py 等）
    3. 打开命令提示符（Win+R，输入 cmd，回车）
    4. 进入程序目录：
       cd /d 程序所在目录
    5. 安装依赖：
       pip install -r requirements.txt
    6. 运行程序：
       python main.py

Q5：提示「无法打开摄像头」怎么办？
A ：请检查以下几点：
    ① 摄像头是否已连接好
    ② 摄像头是否被其他程序占用（比如微信、QQ 视频通话）
    ③ 是否允许应用使用摄像头
       （Windows 设置 → 隐私 → 摄像头 → 允许应用访问摄像头）
    ④ 有些笔记本有物理摄像头开关，检查是否被关上了
    ⑤ 关闭其他可能使用摄像头的程序后重试

Q6：画面很卡，帧率很低？
A ：这是正常的，因为模型在 CPU 上运行。
    一般笔记本 CPU 可以达到 15~30 fps。
    如果特别卡，可以：
    - 关闭其他占用 CPU 的程序
    - 关闭浏览器等大内存程序
    - 确保电脑接通电源（省电模式会降低性能）

Q7：切换语言后有些文字还是中文？
A ：绝大多数文字都会切换，但：
    - 系统弹窗（比如颜色选择对话框）由操作系统决定
    这些属于正常现象。

Q8：程序会保存我的照片或视频吗？
A ：不会。所有检测都在本地实时进行，
    程序不会保存任何图像、视频或人脸数据。
    请放心使用。

Q9：可以检测视频文件或图片吗？
A ：目前只支持实时摄像头检测。
    如果需要检测视频文件或图片，需要修改 main.py 源代码。

Q10：怎么退出程序？
 A ：点击窗口右上角的 × 即可。
     程序会自动关闭摄像头并释放资源。

Q11：支持外接 USB 摄像头吗？
 A ：支持。程序默认使用编号为 0 的摄像头（一般是
     笔记本内置摄像头或第一个 USB 摄像头）。
     如果有多个摄像头，需要修改 main.py 中的
     start_detection 函数里的摄像头编号。

Q12：exe 文件太大（326MB）能不能小一点？
 A ：因为包含了 PyTorch（深度学习框架）和 OpenCV 等大体积库，
     所以 exe 比较大。这是正常现象，无法进一步缩小。
     如果在意体积，可以用 Python 直接运行 main.py 源代码。

Q13：杀毒软件报毒怎么办？
 A ：这是误报。PyInstaller 打包的 exe 经常被杀毒软件误判。
     请在杀毒软件中添加信任即可。
     本程序不含任何恶意代码，可放心使用。
