#YOLO
========================================
  YOLO 实时人脸检测程序 —— 使用说明
========================================


【一、软件简介】
---------------
这是一个基于 YOLOv8n-face 轻量化模型的实时人脸检测程序。
打开摄像头后，程序会自动识别画面中的人脸，并用彩色矩形框标出。

主要特点：
  ✅ 轻量化模型，CPU 即可流畅运行（20fps 以上）
  ✅ 仅检测人脸，不包含人脸识别、年龄、性别等功能
  ✅ 支持多语言界面（中文 / English / 日本語 / 한국어）
  ✅ 检测框颜色可自定义（8 种预设 + 自定义调色板）
  ✅ 置信度 0.5 过滤低质量人脸，NMS 去重
  ✅ 容忍偶发摄像头丢帧，不会轻易自动停止
  ✅ 零配置启动，首次运行自动下载模型


【二、运行环境要求】
-------------------

  操作系统：Windows 10 / 11（推荐）
  也支持 macOS / Linux，但需要自行配置摄像头驱动

  Python 版本：3.8 ~ 3.12（推荐 3.10 或 3.11）

  硬件要求：
  - 必须有可用的摄像头（USB 摄像头或笔记本内置摄像头）
  - CPU：双核以上即可，推荐 i5 及以上
  - 内存：至少 2GB 可用内存
  - 硬盘：至少 500MB 可用空间（模型约 6MB，依赖库约 400MB）

  网络：首次运行需要联网下载模型文件（约 6MB），之后可离线使用


【三、依赖安装说明】
-------------------

▎方法一：一键安装（推荐）
  1. 打开命令提示符（Win+R，输入 cmd，回车）
  2. 进入程序所在目录，例如：
     cd /d C:\Users\你的用户名\Desktop\新建文件夹
  3. 执行安装命令（国内推荐清华镜像，速度快）：
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

▎方法二：手动逐个安装
  如果上面的方法失败，可以手动安装这三个库：
  pip install ultralytics opencv-python pillow -i https://pypi.tuna.tsinghua.edu.cn/simple

▎依赖库说明
  程序运行需要以下 Python 第三方库：

  库名           最低版本   作用
  ------------  --------  ----------------------------------
  ultralytics   8.1.0     YOLO 模型推理引擎
  opencv-python 4.8.0     摄像头读取 + 图像绘制
  pillow        9.5.0     Tkinter 界面图像显示

  这些库会自动安装它们自身的依赖（numpy、torch 等）。

▎检查安装是否成功
  在命令行输入：
    python -c "import ultralytics, cv2, PIL; print('依赖安装成功！')"
  如果没有报错，就说明安装好了。


【四、启动程序】
---------------

▎方法一：双击启动（最简单）
  直接双击文件夹中的 start.bat 文件即可启动。
  （如果双击没反应，右键 → 以管理员身份运行）

▎方法二：命令行启动
  1. 打开命令提示符
  2. 进入程序目录：
     cd /d C:\Users\你的用户名\Desktop\新建文件夹
  3. 运行：
     python main.py

▎首次启动
  首次启动时，程序会自动从 ModelScope 下载人脸检测模型文件
  face_yolov8n.pt（约 6MB），下载完成后自动加载。
  请耐心等待，状态栏会显示下载进度。

  如果下载失败，可以：
  - 检查网络连接
  - 手动下载：https://www.modelscope.cn/models/muse/face_yolov8n/resolve/master/face_yolov8n.pt
  - 把下载好的 face_yolov8n.pt 放到程序目录下

│                                         │
│         【视频画面显示区】                │

▎1. 视频画面显示区
  - 未启动时：显示黑色背景 + 提示文字
  - 检测中：实时显示摄像头画面，人脸被彩色矩形框标出
  - 画面尺寸：640 × 480 像素

▎2. 开始检测按钮
  - 点击后打开摄像头，开始实时人脸检测
  - 模型加载完成前此按钮为灰色不可用

▎3. 停止检测按钮
  - 点击后关闭摄像头，停止检测
  - 检测未开始时此按钮为灰色不可用

▎4. 设置按钮（⚙ 设置）
  - 位于右下角
  - 点击打开设置面板，可调整检测框颜色和界面语言
  - 详细说明见【六、设置功能】

▎5. 状态栏（最底部）
  显示当前程序状态，可能的内容包括：
  · 正在加载模型，请稍候 ...
  · 正在下载模型 ... XX%
  · 正在加载模型 ...
  · 模型加载完成，点击「开始检测」启动摄像头。
  · 检测中  |  人脸数量：N  |  帧率：XX.X FPS
  · 已停止检测。点击「开始检测」重新启动。
  · 无法打开摄像头，请检查设备或权限。
  · 读取摄像头画面失败，已停止。


【六、设置功能详解】
-------------------

点击右下角「⚙ 设置」按钮打开设置面板。

设置面板包含两个区块：

▎区块一：检测框颜色
  可以调整人脸检测框的颜色。

  8 种预设颜色（点击即选）：
    绿色 / 红色 / 蓝色 / 黄色 / 青色 / 紫色 / 白色 / 橙色

  自定义颜色：
    点击「自定义颜色...」按钮，打开系统调色板：
    - 可以用鼠标点击选择任意颜色
    - 也可以手动输入 RGB 值（红/绿/蓝，0~255）
    - 点击「确定」应用，点击「取消」放弃

  当前颜色预览：
    「当前：」右侧的小方块显示当前选中的颜色

  注意：选择颜色后需要点击设置面板右下角的「确定」
        按钮才会真正生效。

▎区块二：界面语言
  可以切换整个软件界面的显示语言。

  支持 4 种语言：
    中文（简体）
    English（英语）
    日本語（日语）
    한국어（韩语）

  操作方法：
    1. 点击下拉菜单
    2. 选择你想要的语言
    3. 点击「确定」按钮
    4. 界面所有文字会立刻切换为对应语言

  切换语言影响范围包括：
    - 窗口标题
    - 按钮文字
    - 状态栏提示
    - 错误提示
    - 设置面板全部文字
    - 画面占位符文字

▎确定 / 取消按钮
  - 确定：保存所有设置并关闭面板
  - 取消：放弃修改，直接关闭面板


【七、使用技巧与注意事项】
-------------------------

▎检测效果最佳的条件
  ✔ 光线充足，面部清晰可见
  ✔ 人脸正对摄像头
  ✔ 面部无大面积遮挡（口罩、帽子等可能降低检测率）
  ✔ 摄像头距离面部 0.5 ~ 3 米效果最好

▎为什么侧脸/快速移动时检测框会消失？
  这是正常现象，不是程序出问题了。
  - 侧脸时人脸特征不明显，模型可能识别不到
  - 快速移动时画面模糊，也会影响检测
  - 程序不会因此自动停止，会继续检测下一帧

▎程序会不会自动停止？
  一般不会。只有以下情况会停止：
  1. 用户手动点击「停止检测」
  2. 用户关闭窗口
  3. 摄像头连续 30 帧读取失败（约 0.3 秒），
     判定为摄像头断开或被占用

  偶发的一帧两帧失败（比如人快速移动时），
  程序会自动跳过，继续检测下一帧。

▎可以同时检测多个人脸吗？
  可以。画面中有几张脸就会框出几张，没有数量限制。
  状态栏会显示当前检测到的人脸总数。

▎检测框太细/太粗怎么办？
  目前框的粗细固定为 2 像素。
  如果需要调整，可以用记事本打开 main.py，
  找到这一行：
    BOX_THICKNESS = 2
  把数字改大（比如 3 或 4），保存后重新启动程序即可。

▎检测太灵敏/太不灵敏怎么办？
  可以调整置信度阈值。
  打开 main.py，找到：
    CONF_THRESHOLD = 0.5
  - 数值越大，检测越严格（漏检增多，误检减少）
  - 数值越小，检测越宽松（漏检减少，误检增多）
  一般 0.4 ~ 0.6 之间比较合适。


【八、常见问题 FAQ】
--------------------

Q1：双击 start.bat 一闪就没了？
A ：可能是 Python 没安装或没加入环境变量。
    请先安装 Python，安装时勾选 "Add Python to PATH"。

Q2：提示"无法打开摄像头"怎么办？
A ：请检查以下几点：
    ① 摄像头是否已连接好
    ② 摄像头是否被其他程序占用（比如微信、QQ 视频通话）
    ③ 是否允许应用使用摄像头（Windows 设置 → 隐私 → 摄像头）
    ④ 有些笔记本有物理摄像头开关，检查是否被关上了

Q3：模型下载太慢/失败怎么办？
A ：可以手动下载：
    下载地址：
    https://www.modelscope.cn/models/muse/face_yolov8n/resolve/master/face_yolov8n.pt
    下载完成后，把 face_yolov8n.pt 放到程序文件夹里，
    和 main.py 放在同一个目录下。

Q4：画面很卡，帧率很低？
A ：这是正常的，因为模型在 CPU 上运行。
    一般笔记本 CPU 可以达到 15~30 fps。
    如果特别卡，可以：
    - 关闭其他占用 CPU 的程序
    - 降低画面分辨率（修改 main.py 里的 DISPLAY_W, DISPLAY_H）
    - 如果有 NVIDIA 显卡且安装了 CUDA，可以用 GPU 加速

Q5：切换语言后有些文字还是中文？
A ：绝大多数文字都会切换，但：
    - 系统弹窗（比如颜色选择对话框）由操作系统决定
    - 模型加载时的日志输出是英文的（来自 YOLO 库）
    这些属于正常现象。

Q6：为什么我选择了韩语/日语，但语音还是中文？
A ：当前版本已移除语音播报功能。
    如果你之前安装过语音播报版本，现在已不再支持。

Q7：程序会保存我的照片或视频吗？
A ：不会。所有检测都在本地实时进行，
    程序不会保存任何图像、视频或人脸数据。
    请放心使用。

Q8：可以检测视频文件或图片吗？
A ：目前只支持实时摄像头检测。
    如果需要检测视频文件或图片，需要修改代码。

Q9：怎么退出程序？
A ：点击窗口右上角的 × 即可。
    程序会自动关闭摄像头并释放资源。

Q10：支持外接 USB 摄像头吗？
 A ：支持。程序默认使用编号为 0 的摄像头（一般是
     笔记本内置摄像头或第一个 USB 摄像头）。
     如果有多个摄像头，需要修改 main.py 中的
     start_detection 函数里的摄像头编号。

【十、技术参数】
---------------

  模型：YOLOv8n-face（轻量化版本）
  模型大小：约 6 MB
  检测类别：仅人脸（1 类）
  置信度阈值：0.5（可在代码中调整）
  NMS IoU 阈值：0.5
  检测框粗细：2 像素（可在代码中调整）
  画面分辨率：640 × 480
  默认框颜色：绿色（BGR: 0, 255, 0）
  支持界面语言：中文 / English / 日本語 / 한국어
  摄像头后端：Windows 下优先 DSHOW，其次 MSMF，最后 ANY
  连续失败容忍：30 帧（约 0.3 秒）
