# YOLO 实时人脸检测程序

基于 YOLOv8n-face 轻量化模型的实时人脸检测程序，支持多语言界面和自定义检测框颜色。

## 功能特点

- 轻量化模型，CPU 即可流畅运行（20fps 以上）
- 仅检测人脸，置信度 0.5 过滤 + NMS 去重
- 多语言界面：中文 / English / 日本語 / 한국어
- 检测框颜色可自定义（8 种预设 + 自定义调色板）
- 容忍偶发摄像头丢帧，不会轻易自动停止
- 已打包成 exe，双击即可运行，无需安装 Python

## 下载使用

### 方式一：下载 exe（推荐，无需安装 Python）

1. 前往 [Releases 页面](../../releases)
2. 下载最新的 `人脸检测.exe`（约 326MB）
3. 双击运行即可

### 方式二：从源代码运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行程序
python main.py
```

依赖列表：
- ultralytics >= 8.1.0
- opencv-python >= 4.8.0
- pillow >= 9.5.0

## 使用说明

1. 双击 `人脸检测.exe` 启动程序
2. 等待模型加载完成（首次启动约 10~30 秒）
3. 点击「开始检测」打开摄像头
4. 人脸会被彩色矩形框自动标出
5. 点击「⚙ 设置」可调整框颜色和界面语言
6. 点击「停止检测」关闭摄像头

详细说明请见 [使用说明.txt](使用说明.txt)

## 设置功能

### 检测框颜色
- 8 种预设色：绿/红/蓝/黄/青/紫/白/橙
- 支持自定义任意颜色

### 界面语言
- 中文（简体）
- English
- 日本語
- 한국어

切换后整个界面文字立刻生效

## 技术参数

| 参数 | 值 |
|------|------|
| 模型 | YOLOv8n-face |
| 模型大小 | 约 6 MB |
| 检测类别 | 仅人脸（1 类） |
| 置信度阈值 | 0.5 |
| NMS IoU 阈值 | 0.5 |
| 检测框粗细 | 2 像素 |
| 画面分辨率 | 640 × 480 |
| 连续失败容忍 | 30 帧（约 0.3 秒） |

## 自行打包 exe

如需自行打包 exe：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name "人脸检测" \
    --add-data "face_yolov8n.pt;." \
    --hidden-import ultralytics.nn.tasks \
    --hidden-import ultralytics.nn.modules.head \
    --clean -y main.py
```

打包后的 exe 在 `dist/` 目录下。
